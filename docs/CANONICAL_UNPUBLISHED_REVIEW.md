# Canonical noindex review — amendment to Publication Pipeline v2

Updated: 2026-09-16. This document records the requested return to the project-wide Country review contract: a finished, approved-visual Country is reviewed at `https://atlas.yagenji.com/countries/{slug}/` **before** final page approval. This narrow amendment supersedes the pre-main GitHub Pages-only review ordering in the 2026-09-14 Pipeline v2 document; it does not relax image approval, asset QA, editorial validation, map QA, accessibility, or final publication approval.

1. Finish Hero, eight scenes, four Taste rasters and their approvals, batch handoff/complete decode, and targeted review Browser QA. The existing GitHub Pages snapshot may remain a staging QA surface but is not the user's final review URL.
2. Serialize the reviewed Country's integration with the existing `country-publication-main` lane. Reconstruct the Country-only overlay on latest `main`, confirm that approved imagery and editorial content did not change since the reviewed source, repair only audited mechanical metadata mismatches, and rerun validations and targeted Desktop/Tablet/Mobile QA. Keep `atlasPublished:false` in the destination registry and Production State, with final approval still pending. No Country-specific CSS or unapproved asset may be introduced.
3. Merge the unpublished Country and verify the exact merge SHA is deployed by Cloudflare, the real Country URL loads, `noindex,follow` is present, the Country is absent from sitemap and normal discovery links, the live registry still reads `atlasPublished:false`, and live Browser QA passes. A queued run or passing CI is not completion. State only records live QA after the checks have actually passed.
4. Show this canonical URL to the user. Only an explicit final page approval may change `atlasPublished:true`, indexability, links, and sitemap membership. Final publication uses the same serialized lane, with a separate publication PR if the unpublished review PR was already merged. The final Cloudflare SHA and target route must be smoke-tested again.

Automated canonical integration must stop on a changed Country, changed approved image bytes, absent approvals, failed checks, ambiguous current main, failed deployment, missing noindex, unexpected sitemap entry, or Browser QA error. Such a stop must not be represented as publication or review completion.

The legacy in-flight publication path stays unchanged. This amendment applies only to `publicationPipelineVersion:2` Country pages with all 13 assets already approved and verified. It does **not** authorize the formal publication of any unfinished or unapproved Country.
