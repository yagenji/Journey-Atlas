## Structural baseline

Every currently published Country Page has:

- 6 visible Country Profile facts
- 8 scenes
- 8 Encounters
- 6 Beyond the Scenery items
- 5 Travel Trivia items
- 1–3 Travel Themes in the taxonomy

This means the broad renewal can start from a structurally consistent shared template rather than from 28 different page structures.

## What this audit does not decide

The automated baseline does not decide:

- whether a Hero should be kept for editorial reasons;
- whether the current 8 scenes are still the best eight discoveries;
- watercolor / photo balance;
- visual recognizability of a real place;
- map visual quality beyond technical rules;
- whether Signature Facts are interesting enough;
- content overlap across Encounters / Beyond / Trivia;
- source freshness / factual quality beyond existing validation;
- Desktop / Tablet / Mobile visual balance.

Those items are handled in the human Country Renewal Audit before each country receives A / B / C classification.
