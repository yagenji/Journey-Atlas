# TAJIKISTAN — content plan

Updated: 2026-08-22

JOURNEY LENSの公開済み4ストーリー（Dushanbe / Wakhan Corridor / Pamir Plateau / Karakul Lake）を基に、JOURNEY ATLASの次ページとして準備する。

## Page concept

**TAJIKISTAN / タジキスタン**

Lead direction: 首都の大きな建築から、アフガニスタン国境沿いの谷、木の消えるパミール高原、深い青の湖まで。道路を進むほど人の気配が薄くなり、大地のスケールが大きくなる国として見せる。

Hero candidate: **Wakhan Corridor / Engels Peak**。Panj River、乾いた岩山、雪峰、細いPamir Highwayを一枚に収める。暗い荒野ではなく、高地の澄んだ空と乾いた色の対比を美しく描く。

## 8 scene candidates

1. **Dushanbe / Istiqlol Square**  
   広い通りと巨大な公共建築。Pamirへ入る前の都市のスケール。

2. **Navruz Palace**  
   外の無骨な都市景観とは対照的な、細密で華やかな内部装飾。

3. **Panj River / Wakhan Corridor**  
   川の向こうにアフガニスタンの村が続く国境沿いの道。

4. **Yamchun Fort**  
   Wakhanの谷を見下ろす古い要塞と乾いた山地。

5. **Engels Peak**  
   高く鋭い雪峰と谷。Wakhan区間の代表的な山岳景観。

6. **Sashil Kul / Pamir Plateau**  
   木が消えた高原、荒い岩と湖、広すぎる空。

7. **Ak-Baital Pass**  
   標高4,600m級の峠。道路そのものが風景になる高地の移動。

8. **Karakul Lake**  
   深い青の湖、茶色い大地、雪をまとい始めた山。北部Pamirの静かな終点。

## Encounters

Pamir Highway / high plateau / snow peaks / alpine lakes / Panj River / border villages / Soviet-era cityscape / homestay

## Visual direction

- Iceland / Antarcticaと同じJOURNEY ATLASの水彩・ガッシュ系統。
- 色は青空、深い湖の青、乾いた黄土・茶、雪の白を主軸にする。
- 「荒涼＝暗い」にはしない。高地の透明な光と、遠くまで抜ける空気感を優先する。
- Heroは山だけを巨大化せず、道路・川・谷を入れて「この道を進みたい」と思える構図にする。
- Dushanbeだけ都市色を入れ、ページ全体の山岳風景との差を作る。
- 地図はPamir Highwayの移動を視覚的に追えるイラスト地図にする。
