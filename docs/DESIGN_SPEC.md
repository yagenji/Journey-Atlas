# JOURNEY ATLAS Design Specification

最終更新：2026-08-21

この文書は、JOURNEY ATLASの確定済みデザイン仕様を定義する。実装と本書が矛盾する場合は、変更理由を確認し、本書または実装を同じ変更内で更新する。未確定事項は勝手に補完せず`TBD`と記載する。

## 1. プロダクトの目的

JOURNEY ATLASは、大人向けの旅のビジュアルアトラスである。

目的は、国について網羅的に勉強してもらうことではない。景色、地図、旅の情報をひとつのページで眺め、その国へ行く自分を想像し、「この国に行きたい」と感じてもらうことである。

### デザインキーワード

- 静か
- 洗練
- 余韻
- 実景への敬意
- 大人向け
- 旅の図鑑
- 一枚のアトラス
- 高い一覧性

### 避ける表現

- 広告的な煽り
- 派手な旅行メディア
- 子ども向け図鑑のようなポップさ
- 業務ダッシュボードのような無機質さ
- 小さな文字を詰め込んだ情報表
- 実在しない地理・景観表現

## 2. JOURNEY LENSとの関係

JOURNEY ATLASは、JOURNEY LENSと静かで余韻のある旅の世界観を共有する。

共通化するもの：

- フォント体系
- 低い声量のタイポグラフィ
- 十分な呼吸を感じる余白
- 写真・実景を主役にする姿勢
- 煽らず、旅への小さな衝動をつくる文章

ATLAS独自の調整：

- LENSより情報量が多いため、本文とUIでは可読性を優先する。
- 明朝体だけに寄せず、情報部分ではゴシック体を使う。
- 高密度でも文字を小さくせず、カードサイズとページの長さで受け止める。

各国ページにJOURNEY LENSへのリンクは置かない。

## 3. 1国1ページ

- 1国につき1ページを基本とする。
- 国ごとの内容はJSONで管理し、共通テンプレートから生成する。
- ページの中心は、その国を象徴するHero、地図、8つの景色である。
- 国を追加しても、基本的な情報階層と操作方法を変えない。
- 現在のURL方式は`?country=slug`である。
- 静的ホスティング上の国別パス設計はTBD。

## 4. ページ構造

```text
Country Page
├── Hero / Header
│   ├── JOURNEY ATLASロゴ
│   ├── 検索・国を探す・メニュー
│   ├── 英語国名
│   ├── 日本語国名
│   ├── 導入文
│   └── Heroイラスト
│
├── Atlas Panel
│   ├── 旅の地図
│   ├── 地図上の①〜⑧
│   ├── この国で見たい景色8選
│   └── この国で出会えるもの
│
├── Travel Information
│   ├── 旅するなら
│   ├── こんな人に
│   ├── 基本情報
│   └── 知っておきたいこと
│
├── Related / CTA
│   ├── 関連国3カ国
│   └── この国に行きたい
│
└── Footer
```

「1ページで俯瞰する」とは、全情報を1画面に縮小して詰め込むことではない。基準となる情報密度と一覧性を保ちながら、Webとして自然にスクロールできる長さにする。

## 5. レイアウト

### 共通

- ページ最大幅：1440px
- 基本背景：白〜生成り
- セクションは大きな色面で分断せず、罫線、角丸、わずかな背景差で整理する。
- 情報を収める必要がある場合、文字を縮小せず、カード高、余白、文章量、ページ長を調整する。

### PC

- Heroは国名・導入文と大型イラストを同一領域に配置する。
- Atlas Panelは地図と8景を左右2カラムにする。
- 8景は2列×4段を基本とする。
- Travel Informationは4カラムを基本とする。
- Related / CTAは関連国3枚とCTAを横並びにする。

### タブレット

- 地図と8景を上下に分割する。
- Travel Informationは2カラムにする。
- 文字サイズはPC用の本文基準を大幅に縮小しない。

### スマートフォン

次の順序で縦積みにする。

1. Header
2. Hero
3. 地図
4. 出会えるもの
5. 景色カード8枚
6. 旅するなら
7. こんな人に
8. 基本情報
9. 知っておきたいこと
10. 関連国
11. CTA
12. Footer

- 景色カードは1列にする。
- Travel Informationは1列にする。
- 関連国は1列にする。
- スマートフォン対応を理由に本文を基準以下へ縮小しない。

## 6. カラー

現行の基本トークン：

| Token | Value | 用途 |
|---|---:|---|
| `--paper` | `#f7f3e9` | ページの生成り背景 |
| `--paper-soft` | `#fbf8f0` | カード、Hero左側、柔らかな面 |
| `--navy` | `#12365c` | ブランド、見出し、番号、主要UI |
| `--navy-deep` | `#092a4b` | 本文、濃い文字 |
| `--muted` | `#66717a` | 補助情報 |
| `--line` | `#d8d0c0` | 罫線、カード境界 |
| `--olive` | `#75824e` | 「この国に行きたい」CTA |
| `--blue-wash` | `#cfdee0` | 地図・画像プレースホルダーの補助色 |

### カラー運用

- ページ全体は生成りと濃紺を中心にする。
- 画像素材は低彩度の水彩調を基本とする。ただし実景の特徴を損なう色変更は行わない。
- CTAのオリーブはページ内の主要アクションに限定する。
- エラー、警告、選択状態の追加色はTBD。必要になるまで勝手に増やさない。
- 状態を色だけで伝えない。

## 7. フォント体系

JOURNEY LENSと次の5書体を共通使用する。

| 役割 | Font | 主な用途 |
|---|---|---|
| Display | Hanken Grotesk | ブランドロゴ、大きな英字見出し（英字国名など） |
| Serif | Newsreader | 英語のセリフ体、補助的なエディトリアル表現 |
| Mincho | Shippori Mincho | Hero導入文など情緒を出したい短い日本語コピー、必要な場合のみCTA |
| Body | Zen Kaku Gothic New | 日本語国名、日本語見出し、景色カード、通常本文、旅行情報、UI |
| Meta | Spline Sans Mono | 地域、番号、月、座標、メタ情報 |

CSS変数：

```css
--display: "Hanken Grotesk", sans-serif;
--serif: "Newsreader", "Times New Roman", serif;
--mincho: "Shippori Mincho", "Yu Mincho", serif;
--body: "Zen Kaku Gothic New", "Hanken Grotesk", system-ui, sans-serif;
--meta: "Spline Sans Mono", ui-monospace, monospace;
```

本文には、JOURNEY LENSと同じ文字レンダリング指定を適用する。

```css
-webkit-font-smoothing: antialiased;
font-feature-settings: "palt";
```

## 8. タイポグラフィ

### 基本原則

- 通常本文：14〜16pxを基本とする。
- 景色カード本文：13〜14pxを下限とする。
- カード見出し：14〜16pxを基本とする。
- メタ情報、英語地名など補助情報：11〜12pxまで使用できる。
- 重要な導入文：16〜20pxを基本とする。
- 本文ウェイトは400、カード見出しは500、主要見出しは600を基本とする。
- 日本語見出しは原則としてZen Kaku Gothic Newを使用する。
- Shippori MinchoはHero導入文などの短い情緒的表現に限定し、カタカナ表記や情報見出しへ広範囲に適用しない。
- 太字を多用しない。
- 文字を小さくして情報を詰め込まない。

### 現行スケール

| Element | Font | Size | Weight | Line height | Letter spacing |
|---|---|---:|---:|---:|---:|
| ブランドロゴ | Hanken Grotesk | 18px | 700 | inherit | 0.25em |
| Hero英語国名 | Hanken Grotesk | 72〜100px | 700 | 1.0 | 0.14em |
| Hero日本語国名 | Zen Kaku Gothic New | 26px（スマートフォン22px） | 500 | 1.5 | 0 |
| Hero導入文 | Shippori Mincho | 18px | 400 | 1.9 | 0.02em |
| 主要セクション見出し | Zen Kaku Gothic New | 23px | 600 | 1.55 | 0.02em |
| 景色カード見出し | Zen Kaku Gothic New | 15px | 500 | 1.55 | normal |
| 景色カード本文 | Zen Kaku Gothic New | 13px | 400 | 1.75 | normal |
| 通常情報本文 | Zen Kaku Gothic New | 14〜16px | 400 | 1.7〜1.85 | normal |
| 英語地名・メタ | Spline Sans Mono | 11〜12px | 400〜500 | 1.5〜1.7 | 要素別 |
| CTA | Shippori Mincho | 19px | 500 | 1.6 | normal |

新しい要素を追加するときは、このスケールに役割を割り当てる。既存の役割で表現できない場合はTBDとして提案する。

## 9. Header / Hero

- ヘッダーはHeroの上部へ統合する。
- 左上にコンパスモチーフとJOURNEY ATLASロゴを置く。
- 右上に検索、国を探す、メニューを置く。
- 検索、国を探す、メニューの最終仕様はTBD。
- Hero左側に地域、英語国名、日本語国名、導入文を置く。
- Heroイラストは右側を中心に広く見せる。
- 左側には生成りのグラデーションを使い、文字の可読性を確保する。
- Heroと本文の間を独立した広告バナーのように分断しない。

## 10. Hero・景色イラスト

- Heroおよび8景の素材は、実景の特徴を忠実に表現する。
- 実在しない道路、建物、山、川、湖、地形、植生、ランドマークを追加しない。
- 地形や建物を構図上の都合で移動・合成しない。
- 画像内に文字、番号、カード、ボタンを焼き込まない。
- 文字とUIはHTML/CSS/JavaScriptで重ねる。
- 素材未設定時は、中立的なプレースホルダーを表示する。
- プレースホルダーで架空の風景を描かない。
- 素材の制作・調達・出典管理方法はTBD。

## 11. 地図＋8選

ページの中心となる構造である。

### 共通データ

- 地図上の①〜⑧と景色カードの①〜⑧は、同じ`scenes`配列から生成する。
- 番号、名称、現地語名、説明、画像、座標を別々のデータへ重複させない。
- 配列順を表示番号とする。

### 地図

- 正確な国土SVGを使用する。
- 地点は正確な緯度・経度を使用する。
- 現行実装は、`map.bounds`内で緯度・経度を相対位置へ投影する。
- 地図上では番号と短い地点ラベルを表示する。
- 国土SVGがない場合は差し替え領域を表示し、推測で国土を描かない。
- 道路やルート線は必須ではない。
- 実在道路または検証済み旅程として正確に表現できる場合のみ、ルート線を使用できる。
- 装飾目的の架空ルートは使用しない。

### 8景カード

- PCでは2列×4段を基本とする。
- 各カードは番号、画像、日本語名、現地語・英語名、短い説明で構成する。
- PCでは画像と文章を横方向に配置する。
- スマートフォンでは1列にする。
- 説明文を収めるために13px未満へ縮小しない。
- 文章量またはカード高を調整する。

### 連動

- カードhoverで対応する地図地点を強調する。
- 地図地点hoverで対応カードを強調する。
- keyboard focusでも同じ状態にする。
- タッチ端末ではtapで選択する。
- 選択状態は`aria-pressed`で通知する。

## 12. 出会えるもの

- 地図の下に、その国で出会える自然、文化、移動体験などを置く。
- 現行Icelandでは8項目とする。
- アイコンと短い名称で構成する。
- アイコン体系の正式な制作ルールはTBD。
- 絵文字や記号を正式アイコンへ置き換える場合も、意味と線の太さを統一する。

## 13. Travel Information

### 旅するなら

- 季節別の旅の特徴を表示する。
- 月、季節アイコン、短い説明を組み合わせる。
- 移動情報は季節情報の下に置く。
- 正確性を確認できない距離や所要時間を掲載しない。

### こんな人に

- 旅の相性を短い人物像として示す。
- 優劣や成長を押しつける表現を避ける。

### 基本情報

- 地域、首都、人口、言語、通貨などを表示する。
- 更新される可能性がある情報は公開前に確認する。
- 更新日と出典の保持方法はTBD。

### 知っておきたいこと

- 天候、道路、自然環境、安全など、旅の前に必要な情報を短く示す。
- 医療、法規制、安全など高い正確性が必要な内容は、最新の公的情報を優先する。

## 14. 関連国・CTA

### 関連国

- 関連国は3カ国を基本とする。
- 関連する理由を短く添える。
- 横長の実景イラスト、英語名、日本語名、理由で構成する。
- 関連国の自動選定ルールはTBD。

### この国に行きたい

- ページの主要CTAとする。
- オリーブ色を使用する。
- ハート、主文言、保存説明で構成する。
- 現行では端末内の`localStorage`へ保存する。
- アカウント同期、サーバー保存、共有機能はTBD。

## 15. アクセシビリティ

- hoverだけに依存しない。
- keyboard focusとtapに対応する。
- focus-visibleを明確に表示する。
- 選択状態を色だけで示さない。
- 操作要素に理解できるラベルを付ける。
- 装飾要素は必要に応じて`aria-hidden="true"`とする。
- 保存結果は`role="status"`で通知する。
- ページ読込領域は`aria-live="polite"`とする。
- 動きは`prefers-reduced-motion`へ対応する。
- 正式なコントラスト基準と監査手順はTBD。

## 16. コンテンツトーン

- 日本語主体。
- 静かで簡潔。
- 説明しすぎず、景色を想像できる余白を残す。
- 「絶対」「必ず」などの過度な断定を避ける。
- セール、ランキング、限定感を煽る表現を避ける。
- 旅行者の優劣を示さない。
- 土地、文化、自然環境への敬意を保つ。
