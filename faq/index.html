01 / BASICS サイトの基本と掲載範囲 JOURNEY ATLASとは・国から探す200件と33の詳細地域
JOURNEY ATLASは、どんなサイトですか？

JOURNEY ATLASは、世界の景色と地図から「行ってみたい場所」を見つけるための旅のビジュアル図鑑です。国・地図・テーマ・季節・景色という5つの入口から旅先を探せます。観光地の順位を決めたり、旅行の予約を完成させたりするためのサイトではありません。

なぜ「国から探す」は200なのですか？

JOURNEY ATLASの「200」は、国連加盟国の数そのものではなく、「国から探す」の一覧・検索対象となる国・地域の数です。詳しい地域は別に掲載しています。内訳は次のとおりです。

  • 193｜国連加盟国：国連に加盟する193か国。
  • 2｜国連非加盟オブザーバー国家：バチカン（国連での名称は聖座）とパレスチナ。
  • 3｜日本が承認する追加の国：上記195に含まれないコソボ、クック諸島、ニウエ。
  • 1｜台湾：旅先として独立して紹介する地域。
  • 1｜南極：国家ではないものの、旅先として掲載。

193＋2＋3＋1＋1＝200です。台湾は日本が国家承認している国には含まれません。また、国連加盟国には日本が国家承認していない北朝鮮も含まれます。国連加盟、オブザーバー資格、国家承認は異なる基準であり、重複して数えていません。

出典：国連の加盟国情報、国連のオブザーバー国家情報、外務省「世界と日本のデータ」。

この数え方は旅行先を探すための編集上の区分であり、国家承認、領有権、国境に対する本サイト独自の法的判断を示すものではありません。

国から探す200件と、詳細地域はどう違いますか？

国から探すの一覧・検索対象は200の国・地域です。さらに33件の詳細地域があり、サイト全体では233の旅先を紹介しています。マイアトラスでは国・地域200件と詳細地域を別々に集計します。

詳細地域の親国別の内訳と公開中の地域名は「このサイトについて」で確認できます。

詳細地域は国検索に含めず、各親国ページ、地図、テーマ、季節、景色から探せます。香港・マカオは中国の特別行政区であり、従来のURLを既存のリンクや保存済みの旅先のために維持しています。

02 / EXPLORE 旅先の探し方 国・地図・テーマ・季節・景色から探す
旅先はどのように探せますか？

トップページの「旅先を探す」メニューには、国から探す・地図から探す・テーマから探す・季節から探す・景色から探すの5つがあります。名前が決まっていなくても、興味や出発時期、心に残る風景から旅先を見つけられます。

5つの探し方は、どう使い分ければよいですか？

何を手がかりに旅先を決めたいかで、使い分けられます。

国から探す：気になる国や調べたい国があるとき。

地図から探す：行きたい地域や位置関係から考えたいとき。

テーマから探す：自然、歴史、街歩き、食など、旅でしたいことがあるとき。

季節から探す：旅行に行ける月が決まっているとき。

景色から探す：行き先を決めず、心惹かれる風景から選びたいとき。

どれか一つに決める必要はありません。気になる国が見つかったら、別の入口から探し直すこともできます。

国名がわからなくても、キーワードで検索できますか？

はい。国から探すの検索欄には、日本語・英語の国名だけでなく、「フィヨルド」「オーロラ」「紅葉」など景色や季節に関する言葉も入力できます。国ページの景観名・説明や季節情報に該当するものがあれば候補として表示されます。

「索引（A–Z）を見る」では英語名の頭文字から探せます。「ランダムに旅先を選ぶ」は、目的地を決めずに世界を眺めたいときの入口です。

地図から探すでは、何ができますか？

地図から探すでは、世界地図から地域を選び、アジア、ヨーロッパ、アフリカ、北米、南米、オセアニア、南極へと進めます。拡大や移動をしながら、その地域にある国・地域を一覧で確認できます。

テーマから探すの8テーマとは何ですか？

「地球の風景」「街を歩く」「時をたどる」「暮らしに出会う」「野生に会う」「海の世界へ」「食をめぐる」「道の先へ」の8つです。テーマから探すでは200の国・地域に加え、該当する詳細地域も見つかります。結果は地域や月で絞り込めます。

テーマは、単にその要素が存在するかではなく、その国を旅先に選ぶ強い理由になるかを基準に設定しています。

季節から探すの「おすすめの時期」はどう決まりますか？

季節から探すで1〜12月を選ぶと、各Country Pageに記載された「おすすめの時期」がその月と重なる国・地域を表示します。さらに地域を絞り込むこともできます。

「おすすめの時期」は旅のヒントであり、毎年同じ天候や景色が見られること、現地の施設が営業していることを保証するものではありません。

景色から探すは、どのように使いますか？

景色から探すでは、国と詳細地域の代表画像（Hero）や景観を一覧で眺められます。気になる画像から国ページに進み、「ほかの景色を見る」で別の組み合わせに切り替えられます。「絞り込む」を開くと、地域・Wishリスト（行きたい国）・景色の種類（山と氷、水辺、祈りの場など）で選べます。「♡ 保存した景色」を選ぶと、このブラウザでお気に入りにした景色だけを表示します。

「景色を流す」とは何ですか？

景色から探すの「景色を流す ▶」を押すと、景色を全画面で一枚ずつ、ゆっくり切り替えながら流します。行き先を探すというより、世界の景色を静かに眺めるための機能です。

そのとき選んでいる絞り込み（地域・Wishリスト・景色の種類・保存した景色）のまま流れるので、「水辺だけ」「行きたい国だけ」「お気に入りだけ」といった眺め方もできます。切り替えの間隔は5〜60秒から選べ、一時停止・前後の移動・全画面表示ができます。気になった景色は「このページを見る」から国ページへ移れます。

キーボードでは ← → で前後、スペースで一時停止・再生、Fで全画面、Escで閉じます。スマートフォンでは左右のスワイプで切り替えられ、画面をタップすると操作ボタンの表示・非表示を切り替えます。

03 / COUNTRY Country Pageと掲載情報 8つの景観・地図・写真表現・情報の確認
Country Pageには何が載っていますか？

国の代表風景や基本情報、旅の地図、実在する地点を題材にした8つの景観などを中心に、食、季節、移動、旅のヒントを紹介しています。国によっては、その国を知る数字、文化や暮らし、旅の豆知識、周遊ルート、次に気になる国も掲載しています。

地図と景観は、その国への興味を広げるための案内です。現地で使う詳しい行程表やナビゲーションではありません。

Country Pageの景色は現地の写真ですか？

Hero（表紙）や8つの景観は、実在する場所を題材に、写実的な表現と柔らかな水彩表現を組み合わせて制作した景観イメージです。現地で撮影した記録写真ではなく、実際の見え方や季節と完全に一致するものではありません。

実際に訪れた場所の写真や旅の物語は、JOURNEY LENSで紹介しています。

8つの景色は、おすすめランキングですか？

いいえ。8景は「観光地Top 8」ではなく、国の多様性を伝えるための編集セットです。地域、地形、都市と自然、建築や文化などのバランスを考え、「この景色から、その国をもっと知りたいと思えるか」を優先して選んでいます。

地図はどの程度正確ですか？

Country Pageの地点は緯度経度を基準に配置し、国土の形も地理データをもとに制作しています。ただし、旅先の位置関係を理解するための編集地図であり、ナビゲーション、測量、法的な境界確認には利用できません。

地図データの出典・ライセンスはこのサイトについてにまとめています。国境の扱いはサイトの編集方針に従いますが、国家承認や領土問題について特定の立場を示すためのものではありません。

人口や面積などの情報は、どこから確認していますか？

政府統計、国際機関、UNESCO、観光局など、項目に応じて信頼性の高い情報源を優先して確認しています。統計の対象年や出典の更新時期は項目・Country Pageによって異なる場合があります。

掲載されている情報は、旅行の判断にそのまま使えますか？

掲載内容はできる限り確認していますが、統計、交通、料金、営業時間、入国条件、治安、現地の状況などは変わることがあります。正確性・完全性・最新性を保証するものではありません。旅行や重要な判断の前には、関係機関、交通事業者、施設などの最新の公式情報をご確認ください。

本サイトの情報を利用したことによって生じた損害等について、JOURNEY ATLASは責任を負いかねます。

04 / MY ATLAS 旅の記録とWishリスト 訪問履歴・行きたい場所・保存・バックアップ
マイアトラスでは、何ができますか？

マイアトラスは、トップページの「景色から探す」の下、ABOUTの上にあります。上部メニューの「マイアトラス」を選ぶと自動で開きます。行った国・地域と行きたい国・地域を一か所で確認でき、各国ページにも移動できます。お気に入りの景色は「景色から探す」で確認できます。

「／200」は国から探すの国・地域の集計です。33の詳細地域は別に保存・表示し、詳細地域を行った・行きたいにしても親の国には自動反映しません。

行った国はマイアトラスの「わたしの地図」で、行きたい国はCountry Pageの「この国に行きたい」で登録します。お気に入りの景色はHeroと8つの景観のハートから保存できます。

「わたしの地図」では、行った国と行きたい国を世界地図に塗り分けて表示し、その地図を画像にして保存・共有することもできます。

Heroや景色をお気に入りに保存するには？

各Country Pageで、Hero画像の下にある説明文の横のハートを押すと、表紙の景色を保存できます。8つの景観は、画像の上にあるハートで保存できます。ハートをもう一度押すと解除できます。

保存した景色は「景色から探す」の「♡ 保存した景色」を選ぶと、Heroも含めてお気に入りだけを地域ごとに表示し、各地域の保存件数を確認できます。

「行った国・地域」は地図以外からも選べますか？

トップページのマイアトラスを開くと、「わたしの地図」から国・地域名で検索し、一覧のチェックボックスで記録できます。マカオや香港など、地図上で小さい地域も選べます。「行った国・地域だけ表示」で記録済みの一覧を確認でき、チェックを外すと解除できます。

一覧のチェックと地図の塗り分けは連動します。記録は利用中のブラウザ内に保存され、別の端末やブラウザには同期されません。

「わたしの地図」を画像にして共有できますか？

はい。マイアトラスの「わたしの地図」で「地図を画像にして共有」を選ぶと、塗った世界地図をPNG画像で保存できます。スマートフォンなど対応する端末では、「共有する」から他のアプリへ直接送れます。

画像には、そのとき選んでいる表示（すべて／行った／行きたい）の塗り分けと、世界・地域ごとの数が入ります。「行きたい」を選んだときは、行きたい国・地域の数になります。画像はブラウザの中で作成し、サーバーへは送信しません。

「行ってみたい国」はどのように使い、どこに保存されますか？

Country Pageの「この国に行きたい」を選ぶと保存できます。トップページの国から探すにある「行ってみたい国」や「マイアトラス」から、保存した国をまとめて見られます。

アカウントには保存せず、利用中のブラウザのローカルストレージに保存されます。別の端末やブラウザには同期されず、サイトデータを削除すると保存内容も消えます。

マイアトラスの記録を、別の端末へ引き継げますか？

自動同期には対応していませんが、「マイアトラス」の「保存データを書き出す」でJSONファイルを保存し、別の端末・ブラウザの「保存データを読み込む」から手動で引き継げます。国・地域200件と詳細地域の行った・行きたい記録、お気に入りの景色が対象です。

読み込んだ記録は既存の記録を削除せずに追加されますが、同じ保存対象がある場合は読み込んだ内容で更新されることがあります。記録は利用中のブラウザのローカルストレージに保存され、本サイトのサーバーには復元用バックアップがありません。大切な記録は定期的にJSONファイルへ書き出し、ご自身で保管してください。

記録が消えたり、別の端末への引き継ぎに失敗した場合はどうなりますか？

ブラウザのサイトデータ削除、端末の変更・故障、ブラウザの不具合などにより、行った国・地域、行きたい国・地域、お気に入りの景色が失われたり、引き継げない場合があります。本サイトは復元用バックアップを保持しておらず、記録の完全な保存・復元・引き継ぎを保証しません。

データ消失や引き継ぎ失敗によって生じた損害については、本サイトの故意または重大な過失による場合など法令上免責が認められない場合を除き、責任を負いません。データの保護には、マイアトラスから定期的にJSONファイルを書き出し、保管してください。詳しくはプライバシーポリシーをご覧ください。

05 / MOBILE スマートフォンで使う iPhone・Androidのホーム画面と保存データ
iPhone・Androidのホーム画面からJOURNEY ATLASを開くには？

iPhone（Safari）：サイトを開く → 共有ボタン（またはページメニューの「共有」）→「ホーム画面に追加」→ 必要に応じて「ウェブアプリとして開く」を選ぶ →「追加」。

Android（Chrome）：サイトを開く → 右上の「︙」→「ホーム画面に追加」または「インストールしてショートカットを作成」→「ショートカットを作成」→「追加」。端末によって項目名が異なる場合があります。

ホーム画面のアイコンからサイトをすぐに開き、マイアトラスやWishリストを利用できます。詳しい手順は「このサイトについて」をご覧ください。

ホーム画面に追加すると、Wishリストはそのまま残りますか？

ホーム画面への追加はアクセスを簡単にする機能であり、保存データの同期やバックアップではありません。ブラウザから開いた場合とホーム画面のアイコンから開いた場合で保存領域が異なり、登録済みのWishリストが引き継がれないこともあります。

アイコンから開いたあと、行きたい国・地域やお気に入りの景色が表示されるか確認してください。引き継ぎが必要なときは、元の画面のマイアトラスで「保存データを書き出す」を行い、利用する画面で「保存データを読み込む」を選びます。記録を残すために、定期的なJSONファイルのバックアップをおすすめします。

06 / OTHER JOURNEY LENS・お問い合わせ サイトの違い・掲載内容のご連絡
JOURNEY ATLASとJOURNEY LENSの違いは何ですか？

JOURNEY ATLASは、まだ知らない世界から行きたい場所を見つけるための図鑑です。JOURNEY LENSは、実際に訪れた場所を写真と物語で記録する旅のメディアです。

トップページの「JOURNEY LENS」から記事を探せるほか、対応するCountry Pageから関連する記事へ進める場合もあります。

誤りを見つけた場合や、連絡したい場合は？

地名、統計、画像、表示上の問題など、気づいた点があればページ下部のお問い合わせからご連絡ください。内容を確認し、必要な修正を行います。

解決しない質問がありますか？

お問い合わせからご連絡ください。
