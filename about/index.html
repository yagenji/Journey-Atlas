このサイトについて

JOURNEY ATLASは、次に行きたい世界と出会うための旅のビジュアル図鑑です。

景色と地図から、その国を知る

旅の計画を完成させるための情報サイトではなく、まだ知らない国や地域への入口をつくることを目的にしています。

景色で惹きつけ、地図で位置関係を理解し、8つの景観から国の多様性を知る。そこから暮らし、文化、季節、食、旅の体験へ興味を広げていく構成です。

8つの景観で、その国の幅を知る

各Country Pageの8景は、その国の「おすすめ観光地Top 8」ではありません。ひとつの有名な景色だけで国を代表させず、8つの異なる入口から、その国の地理的・視覚的な幅を知るための編集セットです。

選定では、地域、地形、都市と自然、海・山・湖・森・平原、建築や文化、季節などができるだけ偏らないように組み合わせます。ただし、地域を均等に埋めること自体を目的にはせず、「この景色からその国をもっと知りたいと思えるか」を優先します。

すべて実在する場所を基準とし、場所を識別できる特徴を保ちながら、同じ静かな水彩表現で並べます。8景を通して眺めたときに、ひとつのイメージでは捉えきれない国の多様性が見えてくることを目指しています。

ランキングではなく、探索のための編集

掲載する景色や場所は「おすすめ順」ではありません。地域、地形、都市と自然、海・山・湖・森・平原、建築や文化などを分散させ、その国の幅が伝わるように選んでいます。

TRAVEL THEMESも、その要素が存在するかではなく、その国を旅先として選ぶ強い理由になるかを基準にしています。

掲載する国・地域

JOURNEY ATLASでは、国連加盟193か国を基礎に、旅行先として独立して探しやすいよう、バチカン市国、パレスチナ、コソボ、クック諸島、ニウエ、台湾、香港、マカオ、南極を加えた計202の国・地域を掲載します。

パレスチナは国連の非加盟オブザーバー国家として扱われています。香港とマカオは中国の特別行政区です。JOURNEY ATLASの掲載区分は、旅行先としての探しやすさを目的とした編集上の整理であり、国家承認や最終的な国境に関する立場を示すものではありません。

JOURNEY LENSとの関係

JOURNEY ATLASは、まだ知らない世界から「行きたい場所」を見つけるための図鑑です。JOURNEY LENSは、実際に訪れた場所を写真と物語で記録する旅のメディアです。

ATLASで場所を知り、実際に訪れた場所はLENSで写真と旅の時間に触れる。二つは役割を分けながら、同じ旅の世界につながっています。

地図データの出典

各国ページの地図は、以下の地理データをもとに、JOURNEY ATLASが投影・単純化・彩色して作成しています。OpenStreetMapのデータを使った地図には、地図の右下にも出典を表示しています。

国境の扱いは日本政府の立場に準拠しており、元データの表示と異なる場合があります。

  • Natural Earth（パブリックドメイン）：国境・国土・湖（1:10m Cultural / Physical Vectors）。全202のうち172の国・地域の地図で使用。
  • GSHHG（Wessel & Smith）（LGPL-3.0）：海岸線・島・湖、周辺の国境（Basemap 2.0.0 に同梱のデータを使用）。全202のうち184の国・地域の地図で使用。
  • NOAA（パブリックドメイン）：アメリカの国土（Basemap の UScounties データ。NOAA Coastal Geospatial Data Project に由来）。
  • USGS（パブリックドメイン）：ミクロネシア連邦・レロ島の海岸線（1:25,000 地形図）。
  • NASA World Wind（パブリックドメイン）：ミクロネシア連邦・アント環礁の小島の形（衛星画像から地図の縮尺で一般化）。
  • geoBoundaries：国の輪郭（gbOpen）。元データが OpenStreetMap の国は OpenStreetMap も併記。元データがパブリックドメインの国：アンドラ、パナマ、セントルシア。使用：アンドラ、バーレーン、ブルネイ、エストニア、フィンランド、グレナダ、キリバス、レソト、リヒテンシュタイン、パナマ、セントルシア、セントビンセント・グレナディーン。
  • geoBoundaries / Erik Frohne（CC BY 3.0）：スウェーデンの国土（gbOpen SWE ADM1 を結合）。
  • geoBoundaries / Wikipedia（CC BY 4.0）：ヨルダンの国土（gbOpen JOR ADM0）。
  • geoBoundaries（Copernicus Sentinel-2 データを加工）（CC BY 4.0）：クック諸島の拡大図の島の形（gbOpen COK ADM0）。
  • geoBoundaries / Wikimedia Commons（CC BY 2.5）：バルバドスの国土（gbOpen BRB ADM1 を結合）。
  • World Resources Institute, Congo Basin Forest Atlas（geoBoundaries 経由）（CC BY 4.0）：赤道ギニアのコリスコ島・エロベイ諸島・アンノボン島の形（gbOpen GNQ ADM2）。
  • © OpenStreetMap contributors（ODbL 1.0）：国の輪郭・小さな島・周辺の海岸線（直接、または geoBoundaries・country-levels-export などを経由）。使用：バーレーン、バルバドス、ブルネイ、エストニア、フィンランド、グレナダ、ホンジュラス、香港、キリバス、レソト、リヒテンシュタイン、マカオ、マーシャル諸島、モナコ、ナウル、ニウエ、パラオ、サンマリノ、サントメ・プリンシペ、シンガポール、セントビンセント・グレナディーン、トンガ、バチカン市国。
  • Singapore Land Authority（Singapore Open Data Licence）：シンガポールのセントーサ島・ジュロン島・ウビン島・テコン島の形（National Map Polygon, 2025年6月）。
  • amCharts geodata：香港の陸地、クウェート市の拡大図。使用：香港、クウェート。
  • georgique/world-geojson（GPL-3.0）：ツバルの海岸線。
