このサイトについて

JOURNEY ATLASは、国・地図・テーマ・季節・景色から次の旅先と出会うためのビジュアル図鑑です。

旅先を探す、5つの入口

旅先の探し方は、「何が決まっているか」によって変わります。行きたい国があるとき、旅でしたいことがあるとき、出かける月が決まっているとき。まだ何も決めていないときも、今の気分に合う入口から世界を探せます。

  • 国から探す：気になる国や調べたい国があるとき。 202の国・地域を一覧やA–Z索引から探せます。国名だけでなく景色や季節のキーワードでも検索でき、ランダムに旅先を選ぶこともできます。
  • 地図から探す：行きたい地域や世界の位置関係から考えたいとき。 世界地図から地域を選び、地理的なつながりを眺めながら国を見つけられます。
  • テーマから探す：自然、歴史、街歩き、食など、旅でしたいことがあるとき。 8つのテーマから旅先を選び、地域や月でも絞り込めます。
  • 季節から探す：旅行に行ける月が決まっているとき。 1〜12月から月を選び、その月が各国の「おすすめの時期」にあたる旅先を探せます。
  • 景色から探す：行き先を決めず、心惹かれる風景から選びたいとき。 さまざまな景観を眺め、気になる一枚から国に出会えます。「ほかの景色を見る」で新たな景観にも出会えます。

Country Pageで、その国の輪郭を知る

それぞれの国・地域のページでは、代表的な風景を入口に、基本情報、地図と地点、8つの景観、食、季節、移動のヒントなどを紹介しています。国によっては、その国らしい数字や文化、旅の豆知識、周遊ルート、関連する旅先も掲載しています。

旅程や予約を完成させるためではなく、地理と景色から国の幅を知り、暮らしや歴史、自然や食への関心を広げるための構成です。

8つの景観は、おすすめランキングではない

各Country Pageの8景は「観光地Top 8」ではありません。ひとつの有名な景色だけで国を代表させず、地域、地形、都市と自然、海・山・湖・森・平原、建築、文化、季節などの多様性が伝わるように選んでいます。

各景観は実在する場所を基準とし、その場所を特徴づける地形や建築などを大切にします。テーマの割り当ても、単に要素が存在するかではなく、その国へ旅をしたいと思う理由になるかを基準にしています。

景観イメージと実際の写真

JOURNEY ATLASの風景や料理のビジュアルは、旅先への興味を広げるための表現です。Country PageのHeroや8景は実在の場所を題材に、写実性と柔らかな水彩表現を組み合わせて制作しています。現地で撮影された記録写真ではなく、実際の見え方や季節を保証するものではありません。

実際に訪れた場所の写真と旅の物語は、別のメディアであるJOURNEY LENSで紹介しています。

202の国・地域を掲載

国連加盟193か国を基礎に、旅行先として独立して探しやすいよう、バチカン市国、パレスチナ、コソボ、クック諸島、ニウエ、台湾、香港、マカオ、南極を加えた計202の国・地域を掲載しています。現在は202のCountry Pageを公開しています。

パレスチナは国連の非加盟オブザーバー国家として扱われています。香港とマカオは中国の特別行政区です。掲載区分は旅行先を探すための編集上の整理であり、国家承認や最終的な国境についての立場を示すものではありません。

気になる国を、あとから見返す

Country Pageにある「この国に行きたい」を押すと、その国を「行ってみたい国」として保存できます。トップページの「国から探す」に戻り、「行ってみたい国」を選ぶと、保存した国だけを表示できます。

保存先は現在利用しているブラウザ内です。アカウント登録や端末間の同期はなく、ブラウザのサイトデータを消すと保存した内容も消えます。

JOURNEY LENSとの関係

JOURNEY ATLASは、まだ知らない世界から「行きたい場所」を見つけるための図鑑。JOURNEY LENSは、実際に訪れた場所を写真と物語で記録する旅のメディアです。

ATLASで場所を知り、LENSで旅の時間に触れる。それぞれの役割から、ひとつの世界を少しずつ深く知ることを目指しています。使い方や掲載情報についてはよくある質問もご覧ください。

地図データの出典

各国ページの地図は、以下の地理データをもとに、JOURNEY ATLASが投影・単純化・彩色して作成しています。OpenStreetMapのデータを使った地図には、地図の右下にも出典を表示しています。

国境の扱いは日本政府の立場に準拠しており、元データの表示と異なる場合があります。

  • Natural Earth（パブリックドメイン）：国境・国土・湖（1:10m Cultural / Physical Vectors）。全202のうち172の国・地域の地図で使用。
  • GSHHG（Wessel & Smith）（LGPL-3.0）：海岸線・島・湖、周辺の国境（Basemap 2.0.0 に同梱のデータを使用）。全202のうち186の国・地域の地図で使用。
  • NOAA（パブリックドメイン）：アメリカの国土（Basemap の UScounties データ。NOAA Coastal Geospatial Data Project に由来）。
  • USGS（パブリックドメイン）：ミクロネシア連邦・レロ島の海岸線（1:25,000 地形図）。
  • NASA World Wind（パブリックドメイン）：ミクロネシア連邦・アント環礁の小島の形（衛星画像から地図の縮尺で一般化）。
  • geoBoundaries：国の輪郭（gbOpen）。元データが OpenStreetMap の国は OpenStreetMap も併記。元データがパブリックドメインの国：アンドラ、パナマ、セントルシア。使用：アンドラ、バーレーン、ブルネイ、エストニア、フィンランド、グレナダ、キリバス、レソト、リヒテンシュタイン、パナマ、セントルシア、セントビンセント・グレナディーン。
