このサイトについて

JOURNEY ATLASは、国・地図・テーマ・季節・景色から次の旅先と出会い、気に入った世界をマイアトラスに残せるビジュアル図鑑です。

旅先を探す、5つの入口

旅先の探し方は、「何が決まっているか」によって変わります。行きたい国があるとき、旅でしたいことがあるとき、出かける月が決まっているとき。まだ何も決めていないときも、今の気分に合う入口から世界を探せます。

  • 国から探す：気になる国や調べたい国があるとき。 基本となる200の旅先を一覧やA–Z索引から探せます。香港・マカオや英国4地域に加え、デンマーク・フランス・オランダの詳細地域も名前で検索できます。国名だけでなく景色や季節のキーワードでも検索でき、ランダムに旅先を選ぶこともできます。
  • 地図から探す：行きたい地域や世界の位置関係から考えたいとき。 世界地図から地域を選び、地理的なつながりを眺めながら国を見つけられます。
  • テーマから探す：自然、歴史、街歩き、食など、旅でしたいことがあるとき。 8つのテーマから国や詳細地域を選び、地域や月でも絞り込めます。
  • 季節から探す：旅行に行ける月が決まっているとき。 1〜12月から月を選び、その月が各国の「おすすめの時期」にあたる旅先を探せます。
  • 景色から探す：行き先を決めず、心惹かれる風景から選びたいとき。 国や詳細地域の代表画像（Hero）と景観を眺められます。「ほかの景色を見る」で別の景色に出会い、「絞り込む」から地域・行きたい国・景色の種類（山と氷、水辺、祈りの場など）で選び、「♡ 保存した景色」でお気に入りだけを表示できます。「景色を流す」を押すと、選んだ景色を全画面で一枚ずつ、ゆっくり流して眺められます。

Country Pageで、その国の輪郭を知る

それぞれの国・地域のページでは、代表的な風景（Hero）を入口に、基本情報、地図と地点、8つの景観、食、季節、移動のヒントなどを紹介しています。国によっては、その国らしい数字や文化、旅の豆知識、周遊ルート、関連する旅先も掲載しています。Heroの説明文の横、各景観の画像上にあるハートから、気になる景色を保存できます。

旅程や予約を完成させるためではなく、地理と景色から国の幅を知り、暮らしや歴史、自然や食への関心を広げるための構成です。

8つの景観は、おすすめランキングではない

各Country Pageの8景は「観光地Top 8」ではありません。ひとつの有名な景色だけで国を代表させず、地域、地形、都市と自然、海・山・湖・森・平原、建築、文化、季節などの多様性が伝わるように選んでいます。

各景観は実在する場所を基準とし、その場所を特徴づける地形や建築などを大切にします。テーマの割り当ても、単に要素が存在するかではなく、その国へ旅をしたいと思う理由になるかを基準にしています。

景観イメージと実際の写真

JOURNEY ATLASの風景や料理のビジュアルは、旅先への興味を広げるための表現です。Country PageのHeroや8景は実在の場所を題材に、写実性と柔らかな水彩表現を組み合わせて制作しています。現地で撮影された記録写真ではなく、実際の見え方や季節を保証するものではありません。

実際に訪れた場所の写真と旅の物語は、別のメディアであるJOURNEY LENSで紹介しています。

なぜ、200の旅先なのか

JOURNEY ATLASの「200」は、単なる国連加盟国数ではありません。世界の国々を広く紹介し、地理的・文化的に独自の旅を見つけられるように定めた、基本となる旅先の数です。

193＋2＋3＋1＋1＝200。内訳は次のとおりです。

  • 193｜国連加盟国：国連に加盟する193か国。
  • 2｜国連非加盟オブザーバー国家：バチカン（国連での名称は聖座）とパレスチナ。
  • 3｜日本が国家承認する追加の国：上記195に含まれないコソボ、クック諸島、ニウエ。
  • 1｜台湾：旅先として独立して掲載する地域。
  • 1｜南極：国家ではありませんが、世界を旅する場所として掲載。

「日本が国家承認する追加の国」は、国連加盟国とオブザーバー国家で既に数えたものを除いた3つです。台湾は日本の国家承認国に含まれません。また、国連加盟国の北朝鮮は日本が国家承認していません。国連加盟・オブザーバー資格・国家承認は、それぞれ異なる基準として区別しています。

出典：国連「加盟国数」、国連「非加盟オブザーバー国家」、外務省「世界と日本のデータ」（2026年11月確認）。

Country Pageの正式な対象は200です。 これとは別に、現在は13の詳細地域ページを公開しています。中国の香港・マカオ、イギリスのイングランド・スコットランド・ウェールズ・北アイルランド、デンマークのグリーンランド・フェロー諸島、フランスのフランス領ポリネシア・ニューカレドニア、オランダのアルバ・キュラソー・シント・マールテンです。これらの地域は200のCountry Pageには加算しません。

香港・マカオは中国の特別行政区であり、中国からたどる詳細地域ページとして紹介しています。両地域の従来のページURLは、既存のリンクや保存済みの旅先を失わないために維持します。ページが存在することと、200のCountry Pageとして数えることは区別しています。

この掲載区分は旅先を見つけるための編集上の整理であり、国家承認、領有権、国境に関する本サイトの法的判断を示すものではありません。

マイアトラスで、旅の記録を振り返る

トップページのメニューにある「マイアトラス」は、「景色から探す」の下にある折りたたみ式の記録ページです。行った国・地域を世界地図に塗る「わたしの地図」と、行きたい国・地域の記録を一か所で振り返れます。お気に入りの景色は「景色から探す」の「♡ 保存した景色」で確認できます。「／200」は基本の旅先の集計です。13の詳細地域は基本の200とは別に記録・表示され、詳細地域を登録しても親の国（中国・イギリス・デンマーク・フランス・オランダ）の記録は自動的には増えません。

  • 行った国・地域：マイアトラスの「わたしの地図」で、地図の国を押すか、国名一覧のチェックで登録します。小さな国・地域も名前から検索して選べます。
  • 行きたい国・地域：Country Pageの「この国に行きたい」で登録します。「国から探す」の「行ってみたい国」からも確認できます。
  • お気に入りの景色：Country PageのHero説明文の横、または8つの景観画像のハートで保存します。「景色から探す」では「♡ 保存した景色」で絞り込めます。

「わたしの地図」では、行った国を紺、行きたい国をテラコッタ色で塗り分けます。「すべて／行った／行きたい」で表示を切り替えられ、地図は拡大・移動もできます。「地図を画像にして共有」を選ぶと、表示中の塗り分けと、世界・地域ごとの数を入れた画像を保存・共有できます。画像はブラウザの中で作成し、サーバーへは送信しません。

記録はアカウント不要で、利用中のブラウザに保存されます。端末間で自動同期はされません。マイアトラスの「保存データを書き出す」でJSONファイルを保存し、別の端末・ブラウザの「保存データを読み込む」で手動引き継ぎができます。行った国・地域、行きたい国・地域、お気に入りの景色が対象です。

本サイトのサーバーには記録の復元用バックアップがありません。ブラウザのサイトデータ削除、端末の変更・故障、ブラウザの不具合などで記録が失われたり、引き継ぎに失敗する場合があります。大切な記録は定期的に書き出し、JSONファイルをご自身で保管してください。

本サイトは記録の完全な保存・復元・引き継ぎを保証しません。データ消失や引き継ぎ失敗によって生じた損害については、本サイトの故意または重大な過失による場合など法令上免責が認められない場合を除き、責任を負いません。詳しくはプライバシーポリシーをご覧ください。

JOURNEY LENSとの関係

JOURNEY ATLASは、まだ知らない世界から「行きたい場所」を見つけるための図鑑。JOURNEY LENSは、実際に訪れた場所を写真と物語で記録する旅のメディアです。

ATLASで場所を知り、LENSで旅の時間に触れる。それぞれの役割から、ひとつの世界を少しずつ深く知ることを目指しています。使い方や掲載情報についてはよくある質問もご覧ください。

地図データの出典

各国ページの地図は、以下の地理データをもとに、JOURNEY ATLASが投影・単純化・彩色して作成しています。OpenStreetMapのデータを使った地図には、地図の右下にも出典を表示しています。

表示地図は出典の地理データに対して投影・単純化・一部データの結合、配色・表示範囲の調整などを施したものです。出典・ライセンスの記載は、データ提供者による本サイトの承認、推奨または内容の保証を意味しません。

国境の扱いは日本政府の立場に準拠しており、元データの表示と異なる場合があります。

トップページの世界地図と「わたしの地図」は、Natural Earth（パブリックドメイン）をもとにJOURNEY ATLASが編集・彩色したものです。

  • Natural Earth（パブリックドメイン）：国境・国土・湖（1:10m Cultural / Physical Vectors）。国・地域の地図187件で使用。
  • GSHHG（Wessel & Smith）（LGPL-3.0）：海岸線・島・湖、周辺の国境（Basemap 2.0.0 に同梱のデータを使用）。国・地域の地図201件で使用。
  • NOAA（パブリックドメイン）：アメリカの国土（Basemap の UScounties データ。NOAA Coastal Geospatial Data Project に由来）。
  • USGS（パブリックドメイン）：ミクロネシア連邦・レロ島の海岸線（1:25,000 地形図）。
  • NASA World Wind（パブリックドメイン）：ミクロネシア連邦・アント環礁の小島の形（衛星画像から地図の縮尺で一般化）。
